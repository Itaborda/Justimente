# Recorridos implementados

## Ciudadanía
Inicio → área jurídica o bienestar → recursos → directorio/asistente → registro e inicio de sesión → solicitud → seguimiento.

## Profesional
El registro admite roles abogado y psicólogo, pero el perfil profesional debe pasar por verificación antes de aparecer como disponible. En esta versión los perfiles son ejemplos no verificados.

## Administración
Se incluye una vista inicial de indicadores. La administración de usuarios, verificación documental y gestión de permisos requiere completar el módulo administrativo y persistencia en PostgreSQL.
